MyBatis SQL Log Merger 帮助文档

简介

MyBatis SQL Log Merger 是一款 Chrome 扩展程序，旨在帮助开发者轻松地将 MyBatis 日志中的 SQL 模板和参数合并成完整的可执行 SQL 语句。

该插件提供了三种不同的使用方式，满足各种使用场景的需求。

使用方式

在线使用教程

1. 独立页面模式

  1. 点击 Chrome 工具栏中的插件图标
  2. 点击"打开独立页面"按钮
  3. 在独立页面中粘贴 MyBatis 日志或分别输入 SQL 模板和参数
  4. 点击"处理SQL"按钮生成完整的 SQL 语句
🚩: 独立页面支持两种输入模式：单框模式（粘贴完整日志）和双框模式（分别输入 SQL 模板和参数）。

2. 页面按钮模式

  1. 在目标网站上激活提取按钮功能（见下方说明）
  2. 在任何网页上选中 MyBatis 日志文本
  3. 点击页面右下角出现的绿色"提取MyBatis SQL"按钮
  4. 在弹出的面板中查看合并后的 SQL 结果

3. 弹出窗口模式

弹出窗口主要用于快速访问插件的主要功能，如打开独立页面、激活页面按钮等。

激活页面按钮功能

默认情况下，页面按钮不会在任何网站上显示。您需要手动激活特定网站的功能：

  1. 导航到您想要使用插件的目标网站
  2. 点击 Chrome 工具栏中的插件图标
  3. 在弹出窗口中，点击"注入提取SQL按钮"旁边的"未激活"状态标签
  4. 状态将变为"已激活"，刷新页面后即可看到提取按钮
💡: 您也可以在设置页面中配置 URL 模式来批量激活多个网站。

使用提取按钮

  1. 在网页上找到并选中 MyBatis 日志文本
  2. 点击页面右下角的绿色"提取MyBatis SQL"按钮
  3. 在弹出的结果面板中查看合并后的 SQL
  4. 您可以使用"复制"按钮将 SQL 复制到剪贴板

手动输入模式

如果您想手动输入 SQL 模板和参数，可以点击提取按钮旁的展开图标：

  1. 点击提取按钮旁的"⋯"图标
  2. 在弹出的面板中分别输入 SQL 模板和参数
  3. 点击"合成SQL"按钮生成结果

输入格式说明

单框模式

支持带或不带 Preparing: 和 Parameters: 前缀的日志：

==> Preparing: SELECT * FROM users WHERE id = ? AND name = ? ==> Parameters: 123(Long), "John"(String)

双框模式

SQL 模板支持以下两种格式：

Preparing: SELECT * FROM users WHERE id = ? AND name = ?
SELECT * FROM users WHERE id = ? AND name = ?

参数支持以下两种格式：

Parameters: 123(Long), "John"(String)
123(Long), "John"(String)

支持的参数类型

  • Long
  • String
  • Integer
  • Double
  • Float
  • Boolean
  • Timestamp
  • Date
  • NULL 值
